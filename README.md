# Hive Academy (linkable preview)

Static site for academy.codex-hive.com. The home page is a public preview of what is here now, starting with Hive Astra. Search engines are still asked not to index it: noindex/nofollow on every page, robots.txt Disallow: /, no sitemap, no analytics.

The Rosetta Logos module remains at `/modules/rosetta-logos/` but is unlisted (no home-page card).

- `tools/make_logos.py` builds web logo assets from the official Hive Academy files.
- `tools/make_og.py` builds the share image.
