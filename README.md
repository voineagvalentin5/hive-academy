# Hive Academy (linkable preview)

Static site for academy.codex-hive.com. The home page is a public preview of what is here now, starting with Hive Astra and the Rosetta Logos research module. Search engines are still asked not to index the site: noindex/nofollow on every page, robots.txt Disallow: /, no sitemap, no analytics. Rosetta Logos is listed on the home page and keeps its preliminary, not-peer-reviewed banner.

- `tools/make_logos.py` builds web logo assets from the official Hive Academy files.
- `tools/make_og.py` builds the share image.
